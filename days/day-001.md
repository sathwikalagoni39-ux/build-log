## Today's proof item
Before/after note on shells.
- Before: "python3 reads the line, python3 is found due to environment variables, a machine code gets created, the low level language will read the machine code, how does it know its finished no idea"
- After: The terminal only draws text. The shell (zsh) reads my line, searches PATH left to right for `python3` (first match wins), starts it as a child process, waits, and gets back an exit code (0 = success).

## Learned, in my words (3 bullets)
- `>` redirects only stdout; errors (stderr) still reach the screen. Redirects run left to right, so `> file 2>&1` is not `2>&1 > file`.
- A pipeline's exit code is the last command's, so `pytest | tee` can turn CI green on failing tests. Fix: `set -o pipefail`.
- Children get copies of exported variables and can't change the parent. That's why `cd` is a builtin, and why any agent I start can read what I export.
