## Learned, in my words (3 bullets)
- Permissions are rwx for owner / group / others (r=4, w=2, x=1). 600 for secrets, 644 for normal files, 755 for scripts and folders. New files are never executable.
- `kill` sends SIGTERM (the program can clean up if it traps it); `kill -9` sends SIGKILL (no cleanup). Exit code = 128 + signal: 143 for TERM, 137 for KILL. Ctrl+Z only pauses (still holds the port); Ctrl+C interrupts.
- /usr/bin belongs to the OS (root), /opt/homebrew belongs to me (brew needs no sudo), my config lives in dotfiles in ~. On a Mac, /etc, /tmp and /var point into /private.
